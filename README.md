# Amena Begum — Portfolio

My personal developer portfolio, built with **Next.js (App Router)**, **TypeScript** and **Tailwind CSS v4**.

**Live:** https://amena-begum-portfolio.vercel.app

## Sections

- **Navbar** — responsive, with a slide-in menu on phones
- **Hero** — designation, photo, resume (view in a popup or download) and social links
- **About me** — my programming journey, the work I enjoy, and life outside of code
- **Skills** — Frontend, Backend & Auth, Tools and Problem Solving shown as keyboard keys
- **Education** and **Experience & training**
- **Projects** — Bazar-Dor, FitLog, Dev Stack and DevConf; each has a details page with the tech stack, description, live link, GitHub link, challenges and future plans
- **Contact** — email, phone, WhatsApp, LinkedIn and GitHub

## Tech

- Next.js 16 + React 19, TypeScript
- Tailwind CSS v4
- Motion (for the menu, popup and horizontal project scroll) — everything else is CSS animation, so the page stays fast
- react-icons

## Run locally

```bash
npm install
npm run dev
```

All the content lives in `src/data/site.ts`.
